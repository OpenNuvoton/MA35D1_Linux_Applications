# Licensing and asset provenance

The shared XML adapter, examples, tools and API schemas retain their Apache-2.0
SPDX notices and the parent example's license. The NAND partition helper is
GPL-2.0, as identified in its source. LVGL is fetched from upstream at
`5a59ad4cf5de8717e2c841e5c0e402803e42ab8b` and retains its MIT license.

Qt and its dependencies retain their respective licenses. Runtime packaging
requires the matching BSP SDK and its license notices; the package does not
redistribute precompiled Qt or board libc. DejaVu font licensing is copied with
the runtime when using the system font. Time-zone data comes from the supplied
zoneinfo database and must retain its applicable notices.

Winbond and Nuvoton logo assets were supplied for the board demonstration;
the marks belong to their owners. The report figures are actual framebuffer
captures from 12 October 2026. The reel soundtrack is newly synthesized original
music. The Kokoro model and voice embeddings are fetched separately and retain
their upstream model licensing; model weights are not checked into this repo.
